阅读—

这是我自学量化的完整路线图，空白版，可以复制去自己打勾。为什么这样排、怎么用 AI 学，见连载开篇；也可以打开交互路线图。学习记录，非投资建议。

最终目标：具备独立投资能力 + 量化研究能力 + Python/数据工程能力 + AI 辅助量化系统构建能力，能够从”投资假设”走到”回测、验证、小资金实盘、复盘”，并逐步把研究流程AI 化。

使用方式：按阶段推进，每完成一个知识点就打勾。不要追求一次学完所有内容；路线图是地图，不是课程目录。

教学约束：后续学习按本路线推进，避免跳跃；每次最多引入 3 个新概念。每节课会明确”当前位置、当前节点、今天学什么、学完什么”。

0. 总体路线

最终形成：

Stage 0：Python、数据与工程基础

目的

让你能够自己处理金融数据，而不是依赖别人已经写好的分析结果。

量化投资的底层不是”指标”，而是数据和程序。

如果这一阶段不过关，后面的回测、因子和 AI 都容易变成”会调用工具但不知道结果是否正确”。

阶段目标

完成后，你应该能够：

  • 看懂 DataFrame

  • 阅读和修改量化代码
  • 使用 Git 管理自己的研究代码

Stage 1：金融市场与股票数据基础

目的

建立”市场语言”。

你需要知道每一个数字到底代表什么，否则很容易把一个看似合理的回测建立在错误的数据上。

阶段目标

看到一份股票行情数据，你能够解释：

每一列是什么、价格为什么会变化、公司行为为什么会改变历史数据、交易为什么存在成本。

1.1 股票市场

  • Stock
  • Share
  • Market Cap
  • Outstanding Shares
  • Float
  • Exchange
  • Ticker

1.2 股票价格

  • Open
  • High
  • Low
  • Close
  • Volume
  • Raw Close
  • Adjusted Close
  • Corporate Actions
  • Bid
  • Ask
  • Bid-Ask Spread
  • Liquidity

1.3 公司行为

  • Stock Split
  • Reverse Split
  • Dividend
  • Buyback
  • Stock Issuance

1.4 交易

  • Market Order
  • Limit Order
  • Stop Order
  • Short Selling
  • Margin
  • Settlement

阶段产出

能够：

  1. 获取可靠的历史行情。
  2. 区分 Raw Price 与 Adjusted Price。
  3. 理解分红、拆股对历史价格和收益计算的影响。
  4. 理解真实交易和”理论价格”的区别。

这个阶段真的有用吗？

非常有用，属于必修。

尤其是 Adjusted Price、公司行为、Bid/Ask、Liquidity，会直接影响后面的收益计算和回测真实性。

Stage 2：基本面投资分析

目的

让你先成为一个懂企业的投资者，而不只是”会跑策略的人”。

量化并不意味着完全不需要理解公司。

尤其是你的最终目标是 AI 辅助量化，AI 最适合帮助你处理大量公司信息，而你必须知道这些信息为什么重要。

阶段目标

给你 AAPL / MSFT / NVDA 等公司，你能够自己回答：

这家公司怎么赚钱？增长来自哪里？利润质量如何？资产负债是否健康？市场给它什么估值？主要风险是什么？

写出第一份完整的公司研究报告：

这个阶段真的有用吗？

有用，但不需要一开始学到专业 CFA 深度。

你的目标是投资和 AI Quant，不是成为传统证券研究员。

这里优先掌握”看懂公司和财务数据”的能力，避免把大量时间花在暂时用不到的细枝末节。

Stage 3：概率、统计与金融数学基础

目的

让你能够判断：

“这个策略赚钱”到底是有规律，还是只是随机结果。

这是量化研究的核心分水岭。

阶段目标

能够理解：

  • 收益为什么有随机性
  • 风险如何衡量
  • 两个变量是否相关
  • 一个结果是否具有统计意义
  • 回归结果应该如何解释

3.1 概率

  • Probability
  • Conditional Probability
  • Expected Value
  • Random Variable
  • Distribution

3.2 描述统计

  • Mean
  • Median
  • Variance
  • Standard Deviation
  • Percentile
  • Z-score

3.3 相关性

  • Covariance
  • Correlation
  • Correlation Matrix

3.4 统计推断

  • Sampling
  • Population
  • Hypothesis Testing
  • p-value
  • Confidence Interval
  • Statistical Significance

3.5 回归

  • Linear Regression
  • OLS
  • Residual
  • R²
  • Regression Coefficient

3.6 后续数学基础

这些不是现在学，但进入高级量化时需要：

  • Linear Algebra
  • Calculus
  • Optimization
  • Time Series
  • Stochastic Processes
  • Stochastic Calculus（高级方向）

阶段产出

能够对一个策略提出：

“这个结果的统计证据是什么？”

而不是只看收益曲线。

这个阶段真的有用吗？

非常有用。

但要注意：

现在不需要为了”量化”先学一整套高等数学。

先学能直接用于数据分析和策略验证的概率统计；高级数学在进入更复杂的 Quant Research 后再补。

Stage 4：Quant Fundamentals

目的

开始真正理解”量化投资是如何衡量收益和风险的”。

阶段目标

给你一个策略，你能够回答：

赚了多少？ 波动多大？ 最大亏损是多少？ 是否跑赢市场？ 承担单位风险获得了多少收益？

4.1 Return

  • Simple Return
  • Log Return
  • Cumulative Return
  • Compound Return

4.2 Risk

  • Volatility
  • Variance

4.3 Risk-adjusted Performance

  • Sharpe Ratio
  • Sortino Ratio
  • Calmar Ratio

4.4 Benchmark

  • Benchmark
  • SPY
  • Excess Return
  • Alpha
  • Beta
  • Tracking Error

阶段产出

建立第一个 Strategy Report：

这个阶段真的有用吗？

极其有用，属于量化投资必修。

因为：

“年化 30%“本身没有意义。

必须同时知道它承担了什么风险，以及有没有只是承担了更多市场风险。

完成第一个自己的策略：

并能进行历史回测。

这个阶段真的有用吗？

有用，但要正确理解。

这些指标本身不是”赚钱公式”。

真正有价值的是学习：

如何把市场现象转换成可测试的假设。

不要把 RSI / MACD 当成圣杯。

这是从”个人技术分析”进入系统化量化研究的重要一步。

你之前看到 quant.ai 中的：

12-1 Momentum、Trend、Reversal、Low Volatility、信号权重搜索

主要就属于这一层。

Stage 7：Backtesting

目的

把策略放进历史市场，模拟：

如果过去按照这个规则交易，会发生什么？

同时理解为什么”回测赚钱”并不等于”未来赚钱”。

阶段目标

自己能够构建一个基础 Backtesting Engine。

  • Position

  • Equity Curve

7.3 Realistic Backtest

自己的：

能够跑：

这个阶段真的有用吗？

极其有用，是核心技能。

这是把”理论策略”变成”可验证系统”的关键。

Stage 8：防止回测欺骗 / Robust Research

目的

这是整个路线中最重要的阶段之一。

防止自己因为：

数据错误、未来数据、幸存者偏差、过拟合

而误以为找到了赚钱策略。

阶段目标

看到一个漂亮回测结果，你第一反应不是：

“发财了。”

而是：

“这个结果可信吗？“

8.1 Bias

  • Look-ahead Bias
  • Survivorship Bias
  • Selection Bias
  • Data Snooping

8.2 Overfitting

  • Overfitting
  • Underfitting
  • Parameter Optimization
  • Degrees of Freedom

8.3 Validation

  • In-sample
  • Out-of-sample
  • Train / Test
  • Walk-forward
  • Rolling Window
  • Cross-validation（了解适用场景，不机械套用）

8.4 Robustness

  • Parameter Stability
  • Regime Stability
  • Sensitivity Analysis
  • Stress Testing

阶段产出

拿一个历史上非常漂亮的策略：

尝试证明：

它为什么可能不是真的。

然后修改研究流程，得到更可信的结果。

这个阶段真的有用吗？

极其有用。

这是”写回测代码”和”做严肃量化研究”的分水岭。

Stage 9：Portfolio / Risk / Real Trading

目的

从：

“一个策略能不能赚钱？”

进入：

“我应该拿多少钱做、怎么分配、如何活下来？“

阶段目标

建立从研究到真实资金的完整流程：

9.1 Portfolio

  • Diversification
  • Correlation
  • Covariance Matrix
  • Position Sizing
  • Concentration
  • Exposure

9.2 Portfolio Optimization

  • Mean-Variance
  • Efficient Frontier
  • Risk Parity
  • Volatility Targeting

9.3 Risk Management

  • Maximum Position
  • Portfolio Exposure
  • Drawdown Control
  • Risk Budget
  • Exit Rules
  • Cash Management

9.4 Trading Infrastructure

  • Broker API
  • Order Management
  • Execution
  • Position Reconciliation
  • Trading Logs
  • Monitoring
  • Alerts

阶段产出

建立自己的：

并用极小的、亏损后不影响生活的资金进行真实验证。

这个阶段真的有用吗？

对”靠投资养活自己”的目标非常有用。

但必须强调：

投资能力 ≠ 保证稳定收入。

尤其在本金很小的阶段，靠投资收益直接养活自己通常不现实。

因此你的职业路线应该同时积累：

前者让你管理资本，后者让你在没有大量本金时也能创造现金流。

Stage 10：AI Quant Engineering

目的

把前面学到的量化研究流程变成：

AI 可以协助执行、研究、解释、监控的系统。

不是让 AI 直接”预测股票”。

阶段目标

最终能够对 AI 说：

“研究美股中 Momentum + Quality + Low Volatility 的组合，并进行严格的样本外验证。”

AI 可以自动：

但核心计算仍由确定性程序负责。

  • 原始数据计算

  • 风险计算
  • 回测结果
  • 订单执行
  • 风控

这些应该由确定性的程序完成。
